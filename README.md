# Workout Routine Generator (운동 루틴 생성기)

맞춤형 운동 루틴을 생성해주는 웹 애플리케이션입니다.

## 주요 기능
- 신체 정보 및 경력에 따른 맞춤 루틴 생성
- 부상 부위 제외 기능
- HIIT 및 장시간 유산소 스타일 선택
- 운동 애니메이션 및 상세 가이드
- 유튜브 영상 링크 연결
- 내장 운동 타이머
- 루틴 저장 및 불러오기 (LocalStorage)

## 기술 스택
- HTML5
- CSS3 (Modern Baseline)
- JavaScript (ES Modules)

## 시작하기
`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.
